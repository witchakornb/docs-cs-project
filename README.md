# แม่แบบเอกสารโครงงานวิทยาการคอมพิวเตอร์

แม่แบบ LaTeX ภาษาไทยที่แยกเฉพาะรูปแบบจากรายงานต้นฉบับ และปรับโครงบทสำหรับเอกสารโครงงาน ไม่มีข้อมูลผู้จัดทำ รหัสนักศึกษา อาจารย์ บริษัท เนื้อหาโครงงาน ผลการทดสอบ หรือรายการอ้างอิงจากรายงานเดิม

ไฟล์ PDF สำหรับดูรูปแบบ: [docs-cs-project-template.pdf](output/pdf/docs-cs-project-template.pdf)

## รูปแบบที่เก็บไว้

- กระดาษ A4 ขอบบน/ซ้าย 3.81 ซม. ขอบล่าง/ขวา 2.54 ซม.
- ฟอนต์ TH Sarabun New เนื้อหา 14 pt ระยะบรรทัด 1.5 และย่อหน้า 1.27 ซม.
- หัวบท 18 pt หัวข้อหลัก 16 pt หัวข้อย่อย 14 pt
- ปกนอกและปกใน ตรามหาวิทยาลัย บทคัดย่อไทย/อังกฤษ และกิตติกรรมประกาศ
- สารบัญ สารบัญภาพ สารบัญตาราง พร้อมเลขหน้าอัตโนมัติ
- เลขหน้าอักษรไทยในส่วนนำ และเลขอารบิกในส่วนเนื้อหา
- โครงบท 1-5 เอกสารอ้างอิง ภาคผนวก และประวัติผู้จัดทำ
- กรอบภาพและตารางว่างสำหรับดูรูปแบบคำบรรยายและรายการในสารบัญ

ข้อความหัวข้อและชื่อสถาบันเป็นส่วนของแม่แบบ ส่วนข้อมูลเฉพาะรายงานเว้นว่างทั้งหมด รูปแบบนี้อ้างอิงการตั้งค่าของต้นฉบับ ไม่ใช่การรับรองข้อกำหนดการส่งโครงงานฉบับล่าสุด

## Build PDF

ติดตั้ง TeX Live หรือ MacTeX ที่มี XeLaTeX และ Biber พร้อมฟอนต์ TH Sarabun New ทั้ง Regular, Bold, Italic และ Bold Italic แล้วรัน:

```sh
bash build.sh
```

ผลลัพธ์อยู่ที่ `output/pdf/docs-cs-project-template.pdf` ส่วนไฟล์ชั่วคราวอยู่ใน `build/` ซึ่งไม่ติดตามด้วย Git สคริปต์หยุดเมื่อคอมไพล์ผิดพลาดและไม่เขียนทับ PDF ผลลัพธ์ด้วยงานที่ build ไม่สำเร็จ

## เริ่มเขียนเอกสาร

1. กรอกข้อมูลใน `info.tex` ค่าเริ่มต้นทั้งหมดที่เกี่ยวกับบุคคล รายวิชา และวันที่เป็นค่าว่าง
2. เขียนบทคัดย่อและกิตติกรรมประกาศใน `frontmatter/`
3. เขียนเนื้อหาใน `chapters/` แล้วแทนที่ `\BlankBody` ด้วยย่อหน้าจริง
4. เปลี่ยนกรอบภาพและตารางว่างเป็นข้อมูลของโครงงาน รวมถึงชื่อหัวข้อย่อยและคำบรรยาย
5. เพิ่มรายการใน `references.bib` และอ้างด้วย `\cite{key}` สคริปต์จะเรียก Biber เมื่อมีรายการอ้างอิง
6. รัน `bash build.sh` อีกครั้ง

การปรับฟอนต์ ระยะขอบ หัวข้อ เลขหน้า และรูปแบบเอกสารอ้างอิงอยู่ใน `preamble.tex` หากต้องการดูข้อมูลใน Overleaf ให้เลือก compiler เป็น XeLaTeX และอัปโหลดฟอนต์/ปรับ `fontspec` ตามการติดตั้งของสภาพแวดล้อมนั้น

Repository นี้แยกจากต้นฉบับโดยไม่นำประวัติ Git ภาพโครงงาน PDF เดิม ไฟล์สำรอง หรือไฟล์ build เดิมเข้ามา
